# Chess Technique Teacher

Learn chess from scratch and see **why** a move is good. Flutter/Dart, same stack as [sudoku-solver](https://github.com/johnkg/sudoku-solver).

See [PLAN.md](PLAN.md) for the design, curriculum ladder and build order. See [CLAUDE.md](CLAUDE.md) for working rules.

## Setup

```sh
# once: generate platform folders (kept out of the scaffold)
~/flutter/bin/flutter create . --project-name chess_solver --platforms=web,android,ios,macos
~/flutter/bin/flutter pub get
~/flutter/bin/flutter analyze
~/flutter/bin/flutter test
~/flutter/bin/flutter run -d chrome
```

If `flutter create` rewrites `lib/main.dart` or `test/widget_test.dart`, restore them from git.

## Status

Compiled: `flutter analyze` is clean, `flutter test` passes (165 tests), the web app runs in Chrome and `tool/solve.dart` runs.

- Engine (`lib/engine/`): position, search, eval, attacks, explainer, SAN, "why is my move bad", puzzle rater.
- Ideas: checkmate, back-rank mate, smothered mate, double check, free/winning capture, fork, discovered attack, removing the defender, pin, skewer, castling, development, center.
- Lessons (`lib/lessons/lessons.dart`, generated): piece moves, check/checkmate/stalemate, then one lesson per idea, each with a board example the real engine must confirm.
- Puzzle library (`lib/puzzles/library.dart`, generated by `tool/curate.py`): positions with one clear answer, rated by idea and tier 1-5.
- Logic verified in Python (all pass): `tool/perft_mirror.py`, `check_mirror.py`, `check_ideas.py`, `check_more.py`, `check_mistakes.py`, `check_rater.py`, `check_lessons.py`, `check_library.py`.

CLI: `dart run tool/solve.dart "<fen>" [depth] [move-to-critique, e.g. e2e4]`.

## App screens
Learn (26 lessons, "Show me" plays the move and explains it), Practice (24 puzzles by tier, hints, wrong-move explanations, progress saved), Board (free play, best move with reasons, rate my last move, paste FEN). UI smoke-tested in Chrome only (widget tests cover the tab shell).
